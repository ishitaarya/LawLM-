# Phase 4 — Decoder-only Transformer\n\n## Objective\n\nBuild the LawSuit LLM neural network from randomly initialized weights.\n\nNo GPT, Llama, Mistral, Qwen, or other pretrained LLM weights are used.\n\n## Architecture\n\nThe initial model uses:\n- Vocabulary: 10,000 tokens\n- Context length: 256\n- Embedding dimension: 384\n- Transformer layers: 4\n- Attention heads: 6\n- Feed-forward dimension: 1,536\n- Dropout: 0.1\n- Decoder-only causal attention\n- Tied token embedding/output weights\n- Random initialization\n\nThe exact parameter count is calculated by the model instead of being assumed.\n\n## What is implemented\n\n### 1. Token embedding\nToken IDs are converted into 384-dimensional vectors.\n\n### 2. Positional embedding\nA learned positional embedding represents positions 0–255.\n\n### 3. Causal self-attention\nThe implementation explicitly creates:\n- Query (Q)\n- Key (K)\n- Value (V)\n- attention scores\n- causal mask\n- softmax attention weights\n- weighted value output\n\nFuture tokens are masked so a position cannot see later tokens.\n\n### 4. Feed-forward network\nEach Transformer block applies:\n`Linear(384 → 1536) → GELU → Linear(1536 → 384)`\n\n### 5. Residual connections and LayerNorm\nEach block uses pre-normalization and residual connections around attention and the feed-forward network.\n\n### 6. Language-model head\nThe final hidden states are projected to 10,000 vocabulary logits. The output head shares weights with the input token embedding.\n\n### 7. Causal language-model objective\nFor a token sequence `t1, t2, t3, ..., tn`, the model learns the next token at every position. Cross-entropy loss compares predicted next-token probabilities with the target tokens.\n\n## Dataset handoff\n\nPhase 3 produced:\n- train: 880,077 tokens\n- validation: 49,890 tokens\n- test: 49,789 tokens\n- vocabulary: 10,000\n\n`src/training/causal_lm_dataset.py` converts the tokenized JSONL splits into fixed 256-token causal samples.\n\nThe token stream inserts EOS (`id=3`) between legal provisions and forms blocks of `block_size + 1` tokens so each sample can be shifted into `input_ids` and `targets`.\n\nThe final incomplete block is dropped by default for efficient fixed-size training.\n\n## Smoke test\n\n`python src/training/smoke_test_phase4.py`\n\nThis verifies:\n1. model construction\n2. parameter counting\n3. forward pass\n4. logits shape\n5. cross-entropy loss\n6. backward pass\n7. gradient creation\n\nDataset test:\n`python -m pytest src/training/test_phase4_dataset.py`\n\n## Important distinction\n\nA larger legal corpus does not automatically require a larger model.\nThe model has approximately 10M parameters by design, while the legal corpus can later scale from thousands to hundreds of thousands of provisions. Data is processed incrementally.\n\n## Phase 5 handoff\n\nAfter Phase 4 passes its smoke tests, Phase 5 will add:\n- DataLoader\n- AdamW optimizer\n- learning-rate schedule\n- gradient accumulation\n- gradient clipping\n- checkpoint saving/loading\n- training loop\n- validation loss\n- experiment logging\n\nDo not start long training until the Phase 4 smoke tests pass.
